HTML 教材讲义编写规范

用定义、推导、例题、源码和实验，建立可迁移的工程能力。

更新：2026-10-14 · HTML 教材版 · 离线阅读 / A4 打印

2026-10-13 起，所有课程讲义以 HTML 作为正式交付格式。课程采用理工科教材的教学组织方法，中文原创讲解，保留必要英文术语和源码符号。参考优秀教材的严谨推演、例题与习题结构，不复制具体教材的文字或版式。

一、每课的教学结构

每课从一个具体工程问题开始，说明前置知识、学习目标、时间预算和应提交的证据。主体按概念依赖组织：定义与直觉 → 明确假设 → 机制或推导 → 完整例题 → 源码映射 → 受控实验 → 习题与复盘。章节应当是连贯讲解，而不是把术语清单或幻灯片提纲转换成网页。

每课只推进一个主要能力，阅读任务通常限定在 3–5 个核心文件或符号。高级架构先给索引和边界，完成前置知识后再展开。必做、选做和进一步阅读明确区分；选做不增加每周 5 小时的必修预算。

二、定义、公式与推导

首次出现的术语给出英文名称和工程含义。公式应先说明适用模型、精度、分片、缓存或负载条件，再列出变量与单位，解释每个系数来源。涉及容量时区分 byte、KiB、MiB、GiB 与十进制单位；涉及性能时明确时间边界和工作量。

关键公式按章编号。使用原生 MathML 排版，支持本地浏览器离线阅读；式子过长时允许公式区域横向滚动。不能只展示公式而没有说明推导、近似、忽略项和实际验证方法。

三、例题与概念检查

例题采用“已知 → 建模 → 计算 → 检查 → 工程解释”。数字计算写出中间步骤和单位，至少有一次数量级或边界检查。例题帮助学员学习解决问题的方法，不只是展示结果。

重要概念之后设置少量检查题。参考答案默认折叠，让学员先独立解释。章末包含概念、估算、源码与实验设计题，给出必要参考推理和通过标准。通过标准依据实际理解与数据，不因讲义已经生成而判定课程完成。

四、图、表和交互

2026-10-13 补充要求：课程中需要插图解释的地方，调用画图工具生成教学插图，并插入对应 HTML 正文。每课先检查文字难以表达的空间关系、状态变化、数据流、存储层次和硬件结构，选择能帮助理解的插图；按需要绘制，不机械规定张数。使用内置 image_gen 绘图工具，沿用教材配色与清晰的标注风格。

绘图前明确教学目标、图中必须成立的数量关系、箭头方向、状态和适用假设。生成后逐项核对技术内容、文字和可读性；有错误时通过画图工具修正，核对完成后再插入。图中的教学数字与真实实测数据明确区分。插图配中文图注、编号、必要图例和替代文本；图片内的少量英文标签在正文或图注解释。

插图原文件保存到 assets/figures，最终提示词和核对记录保存在 records。构建时把图片嵌入 HTML，保证单个讲义文件离线打开仍能看到图片。已有交互图、公式和数据图继续承担精确推演、计算和测量展示，生成插图帮助建立直观理解。

图表按章编号，并写明它表示状态、数据流、函数调用还是时间关系。示意数据显式标注为教学构造，不能伪装成硬件实测。涉及进程和设备边界时画出通信和状态归属。

交互用于检验因果关系，例如状态推进、容量变化和成本比较。计算器写明假设，检查输入和数值范围。没有 JavaScript 时保留核心正文、静态例题与状态表；图使用可访问的 SVG 标题和描述。

五、源码与证据

源码引用包含文件、类或方法、阅读快照和短片段；行号作为导航辅助。讲清输入输出、shape/layout、状态拥有者、进程/设备边界以及分配释放。省略后的片段明确标为阅读提示，不能伪装成可直接替换的实现。

区分四种证据：本地源码事实、官方资料说明、有假设的理论估算、实际实验观察。官方模型配置不能替代本地 checkpoint revision；latest 文档不能证明当前镜像支持所有功能；源码存在不能证明运行路径已经启用。

六、实验与结论

先提出问题或假设，明确固定变量、控制变量、测量边界和预期辨别能力，再给出可执行命令。版本、模型、数据、重复测量和日志必须可追溯。结论分别写“观察到什么、可能为什么、还缺什么证据”。没有实测就保持待验证，不填入估计的性能成绩。

环境记录和排障计入周预算。脚本与报告模板可以是 Python、JSON 或 Markdown；这些是实验附件，课程讲解本身仍以 HTML 交付。

七、阅读与输出规范

讲义采用清晰层级、适合中文的行距与阅读宽度、侧边目录、移动端布局和 A4 打印样式。参考解答打印时展开；打印后恢复原先的折叠状态。图表、公式、代码与正文保持克制的视觉区别，颜色不是唯一信息载体。

正式 HTML 内嵌样式、脚本与教学插图，不依赖 CDN、在线字体或构建服务。直接用现代 Chrome/Edge 打开即可阅读；原生 MathML 在其他浏览器中的效果以其支持为准。课程入口只为已经写好的章节提供讲义链接，后续章节按学习反馈逐课编写。
